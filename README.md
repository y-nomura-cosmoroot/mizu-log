# みずログ（mizu-log）

入院患者の **飲水量・尿量・体温・血圧・脈拍・体重・便・食事・内服** を、紙の記録表の代わりにスマホで記録するWebアプリ。

紙の記録表では、1時間の枠内に複数回の飲水・排尿があるたびに書き換えや合算の手計算が必要だった。みずログでは **そのつど入力するだけで同じ時間枠の記録が自動で合算** される。記録するのは患者本人、看護師は同じ端末の画面を一緒に見て確認する（看護師専用の操作はない）。

## 主な機能

### 💧 飲水量/尿量（ホーム）

- 画面全体が左右2分割の「水タンク」。左=飲水（青）・右=尿量（黄）で、その日の合計に応じて水位が上がる（満タン基準 2000ml）
- クイックボタン（＋50 / ＋100 / ＋150 / ＋200 ml）または自由入力でワンタップ記録
- 「この時間の量」「今日の合計」「3つの小計帯」をその場で確認できる
- 飲み忘れがあるときは画面上部にアラートバナーを表示（タップでおくすりタブへ）

### 🩺 バイタル

- 体温（34.0〜41.0℃の選択式）・血圧（上/下）・脈拍・体重（0.5刻み対応）を数値入力。どれか1つだけでも記録できる（1回の保存で1レコード）
- 体温に応じて中央の人体シルエットの色が変化（35℃未満=薄い水色「低体温」/ 平熱=青 / 37℃以上=オレンジ「微熱」/ 38℃以上=赤「高熱」）
- 体重に応じてシルエットの体型が連続的に変化（40kg以下=最も細い / 55kg=標準 / 90kg以上=最も太い。お腹が膨らむ・顔が丸くなる・手足が太くなる）
- 右胸の心臓が脈拍と同じ速さで拍動（100超=周りに効果線 / 60未満=青くなる。未入力でも通常の心拍で拍動）
- 血圧（上）に応じた表現（140以上=腕に血管が点滅しながら浮き出る / 90未満=頭の周りにめまいの渦巻き）
- シルエットのエフェクトは入力中の値、無ければその日の最新記録の値で表示され続ける（例: 18時の記録が高熱なら赤いまま）
- 便・食事はボタンをタップするだけで回数を記録

### 💊 おくすり

- 服用タイミング（朝・昼・晩など）ごとに「のんだ！」をタップしてチェック
- マスタ編集で、タイミングの追加・削除・並び替え、薬の登録とタイミングへの紐付けができる（薬名は自由入力、量は数値+単位のプルダウン: 錠 / 袋 / mg / g）
- タイミングごとに **飲む曜日（月〜日）** を選べる（最低1つ）。チェック画面の各行にはマスタと同じ月〜日のチップが並び、見ている日の曜日にリングが付く。曜日を指定したタイミングにはさらに「きょうは 金よう日だからのまない日」の一文が出る（曜日と判定を同じ強さで表示）。対象外の曜日はその行が薄くなり、「のんだ！」ボタンは出ず飲み忘れ判定からも外れる。既存データ（曜日指定なし）は全曜日で飲む扱い
- その日のチェックが揃っていないと「飲み忘れあり！」のアラートを表示。全部揃うと「飲み忘れなし！えらい！」（その日に飲むタイミングが1つもない日は「のむおくすりの ない日」）

### 📋 りれき

- 飲水量/尿量・バイタル・おくすりの3タブで、その日の記録を時間帯ごとに一覧
- 時間の行をタップすると個別の記録を展開。「なおす」（値の修正）・「けす」（削除）ができ、合計・小計は自動で再計算される
- バイタルの時間行サマリは、同じ時間に部分入力の記録が複数あっても項目ごとに最新値を統合して表示（例: 1回目=体温+体重、2回目=血圧+脈拍 → 4項目すべて表示）

## 記録のルール

- **1日 = 0:00 〜 23:59（暦日）**。日付が変わると新しい記録日になる
- 小計は8時間ずつの3帯: **0〜7時 / 8〜15時 / 16〜23時**
- 日付が変わってから飲んだ分（例: 0時すぎの「ねる前」）は、‹ で前の日に戻ってチェック・記録する
- 記録時刻は基本「今」だが、**過去の時刻・過去の日付を選んで後から記録できる**（例:「4時に飲んだ分を5時に記録」「昨日の分を今日つける」）。未来の日付は選べない

## データの保存について

- 記録はすべて **その端末のブラウザ内（localStorage）** に保存される。サーバーやデータベースには送信されない
- そのため **ブラウザのデータ消去や端末の変更で記録は失われる**。別の端末とのデータ共有もできない（1台のスマホで使う前提）
- 個別の入力履歴をすべて保持しており、合計・小計は表示のたびに計算される

## 開発

### セットアップ

```powershell
npm install
npx playwright install chromium   # E2Eテストを実行する場合
```

### コマンド

```powershell
npm run dev          # 開発サーバー http://localhost:3000
npm run test         # ユニットテスト（Vitest）
npm run lint         # ESLint
npm run build        # 本番ビルド
npx playwright test  # E2Eテスト（本番ビルドを .next-e2e に作成しポート3100で自動実行）
```

### テスト

- **ユニットテスト**（`src/lib/__tests__/`）: 記録日の0時境界（記録日=暦日）・小計帯の境界・集計・内服アラート判定（曜日指定込み）・旧データ（14時起点・v2）の移行（`migrate.test.ts`）・カレンダー生成・バイタルエフェクト判定（低体温/微熱/高熱・体型係数・脈拍・血圧の各境界値）を検証
- **E2Eテスト**（`e2e/`）: Playwrightで実際の画面操作を検証。`page.clock` で時刻を固定し、同一時間内の合算・過去時刻/日付への記録・0時境界での記録日切り替わり（開いたまま日付を跨いでも今日に追従）・旧データ（14時起点・v2）からの移行・履歴の編集/削除・内服マスタ編集（曜日指定含む）からアラート消灯まで・リロード後のデータ保持・バイタルエフェクト（体型/心臓/血管/めまいの表示切替と持続）・検索除けを網羅
- E2Eは本番ビルドを専用ディレクトリ `.next-e2e` に作成しポート3100で実行するため、ポート3000の開発サーバーを起動したまま実行できる

### 技術スタック

- [Next.js](https://nextjs.org)（App Router）+ TypeScript
- [Zustand](https://zustand.docs.pmnd.rs/)（状態管理・localStorage永続化）
- Vitest / Playwright（テスト）
- ホスティング: Vercel（予定）
- モバイルUX: 入力欄フォーカス時に画面が自動ズームしないようviewportでズームを無効化している

### 検索除け

公開URLでも検索エンジンに載らないよう、`<meta name="robots" content="noindex, nofollow">`（Metadata API）と `robots.txt` の全面 `Disallow` を設定している。認証は無い。
